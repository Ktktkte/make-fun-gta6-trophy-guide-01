An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Trophy names, descriptions and grades are as PlayStation publishes them; every guide is written in our own words and cites its sources. It includes a 3-stage platinum roadmap (~200 hours, difficulty 4/10), the game's one potentially missable trophy flagged with its Chapter 1 warning, and a checklist tracker saved in the browser with export/import, filters by kind and grade, counters for count-based trophies, and a spoiler mode that hides story trophies until earned. No network needed — serve `app/` and open it.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
# writes /tmp/out/app, /tmp/out/screenshots and /tmp/out/dossier.json
```
